# Smart Paws 🐾

Smart Paws is an AI-powered pet care platform developed as a Final Year Project. The application helps pet owners manage pet health records, receive AI-assisted health guidance, identify pet breeds, generate nutrition plans, analyze pet behavior, and locate nearby veterinary services.

## Features

- Secure Authentication (Email & Google Sign-In)
- Vaccination Record Management
- AI Symptom Checker
- AI Breed Identification
- Personalized Nutrition Recommendations
- AI Pet Behavior Analysis
- Nearby Vet Clinics & Appointment Booking
- Cross-Platform Mobile Application

## Tech Stack

### Frontend
- Flutter
- Dart

### Backend
- FastAPI
- Python

### Database & Authentication
- Firebase Authentication
- Cloud Firestore

### AI & Machine Learning
- Llama 3
- Retrieval-Augmented Generation (RAG)
- VGG16 Transfer Learning
- PyTorch
- XGBoost

## Key Achievements

- Developed a complete cross-platform mobile application using Flutter.
- Built three independent FastAPI-based AI microservices.
- Implemented an AI-powered symptom checker using RAG and Llama 3.
- Achieved 87.5% breed classification accuracy using a fine-tuned VGG16 model.
- Integrated Firebase Authentication and Cloud Firestore for secure cloud-based data management.
